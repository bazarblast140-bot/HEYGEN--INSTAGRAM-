Paise Ki Pathshala Uploader

Paise Ki Pathshala Uploader is a private automation tool used to publish educational finance and stock-market learning videos to the owner's YouTube channel.

Purpose

The application uses Google OAuth authorization to upload videos to the authorized YouTube channel. It does not sell Google account information or YouTube data.

Contact

For questions about this application, contact the developer using the email address configured in Google Auth Platform.
